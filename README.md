# Campus connect | link-https://realtimechatapp34235.vercel.app/

## Project Summary
 Developed a full-stack real-time chat app with user authentication, direct messaging ,
adding friends , and real time updates .
• Used Redis as the primary database to store messages, sessions, and active user data
for high-speed access.
• Integrated Socket.io for real-time communication with features like live message notifi-
cations and live chat updates
• Built a responsive UI using Tailwind CSS and deployed frontend on Vercel, with a
scalable backend using Express + TypeScript.

## Tech Stack
 Next.js, Node.js, Socket.io, Redis (DB), Express, TypeScript, Tailwind CSS, Vercel
