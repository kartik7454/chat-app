# 💬 Real-Time Chat Application

A modern, real-time messaging platform designed to deliver a seamless communication experience similar to apps like WhatsApp or Slack. It focuses on instant messaging, secure authentication, and a clean, responsive UI.

---

## 🚀 Core Features

### ⚡ Real-Time Messaging
- Send and receive messages instantly  
- No page refresh required  

### 👥 Friend Management System
- Search and add friends using email  
- Accept or reject friend requests  
- Maintain a dedicated friend list  

### 🔔 Instant Notifications
- "Unseen Chat" toasts for new messages  
- Visual indicators for unread chats  

### 🔐 Secure Authentication
- Complete login/logout system  
- Ensures privacy of user data and conversations  

### 🖥️ Responsive Dashboard
- Central hub for:
  - Active chats  
  - Friend requests  
  - Starting new conversations  

---

## 🧠 How It Works

### 🔑 Onboarding
- Users log in to access their personalized dashboard  

### 🤝 Building Connections
- Send a friend request via email  
- Once accepted, users appear in the chat list  

### 💬 Communication
- Click on a friend to open a chat window  
- Messages update in real-time for both users  

### 📢 Stay Updated
- Get notified of new messages even when not in the chat
